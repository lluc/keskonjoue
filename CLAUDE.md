### ABC Notation Tool

When ABC source files in `tools/notations/` are modified, regenerate the JSON:

```bash
cd tools && python abc2json.py
```

This outputs `src/data/notations.json`.

## Architecture

**Keskonjoue** is an offline-first PWA for browsing and playing traditional folk music (danses). All data is bundled statically — there is no backend.

### Data Layer

- `src/data/data.json` — dance and music metadata
- `src/data/notations.json` — ABC notation for each piece (generated by `tools/abc2json.py`)
- `src/service/store.service.ts` — initializes a **TinyBase** in-memory store with tables, relationships (`musicDance`), and indexes (`danceAsc`)

Components read from TinyBase; nothing is persisted to localStorage or a server.

### Routing

React Router with four routes:
- `/` → `Home.tsx` (dance list via `DanseListe`)
- `/dance/:slug` → `Dance.tsx` (music list for a dance via `MusiqueListe`)
- `/music/:slug` → `Music.tsx` (ABC notation renderer + ABCJS synth player)
- `/search` → `Search.tsx` (full-text search over music table)

### Music Playback

`Music.tsx` uses **ABCJS** to render ABC notation to SVG and play it via a `SynthController` with FluidR3_GM soundfonts. Speed control ranges from 25% to 200%. Soundfonts are precached by the service worker for offline playback.

### PWA / Offline

- `service-worker.js` uses **Workbox** with a cache-first strategy for navigation and precaches all assets (JS, CSS, PNG, SVG, MP3 soundfonts)
- `src/hooks/useServiceWorker.ts` monitors SW lifecycle and reports status to `OfflineStatus.tsx`, which shows a French-language snackbar
- `vite.config.ts` uses `injectManifest` strategy and splits ABCJS and MUI into separate manual chunks

### UI

Material-UI (MUI) v5 with Emotion. Theme defined in `src/themes/theme.ts`. All user-facing text is in **French**.
